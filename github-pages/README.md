# Kubernetes CKA — Sổ tay tiếng Việt

12 phần, 55 bài ghi chú Kubernetes CKA tự biên soạn bằng tiếng Việt.

HTML/CSS/JavaScript thuần, không cần build. Mỗi phần đều có trang mở đầu.

## GitHub Pages

Đưa các file trong thư mục này vào gốc repository. Trong Settings → Pages, chọn Deploy from a branch, branch main, thư mục / (root), rồi Save.

Đường dẫn dự kiến khi repository là quywork62/kubernetes-cka:
https://quywork62.github.io/kubernetes-cka/

Trang mở đầu: #/phan/1. Nội dung bài học nằm trong content.js.

Nội dung độc lập theo chủ đề CKA, không phải bản dịch hay tài liệu chính thức Udemy/KodeKloud. Các lệnh mẫu cần cluster lab; trang web không thực thi lệnh Kubernetes. Tiến độ lưu trong localStorage của trình duyệt.
